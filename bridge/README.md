# harness-mcp (bridge)

This folder holds the harness-mcp server. Setup, configuration, usage and troubleshooting are in the
main [README](../README.md). Design and threat model: [DESIGN.md](../DESIGN.md).

Quick start (Windows, Node 24.22.1+, cloudflared installed):

```bash
npm install
```

```bash
npm run setup
```

```bash
.\start.cmd
```

Then open http://127.0.0.1:8788 on this PC.
